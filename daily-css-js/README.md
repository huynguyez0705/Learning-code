# Bài tập CSS + JS mỗi ngày

Mỗi ngày một bài ngắn (30–45 phút) kết hợp CSS và JavaScript thuần. Cách dùng: mở thư mục `starter/` của bài (`style.css` đã có sẵn `:root` chứa biến màu, font, khoảng cách cùng reset cơ bản), đọc file `.md` cùng tên với thư mục bài, làm theo phần gợi ý từng bước, tự kiểm tra bằng checklist, rồi mới mở `solution/` hoặc phần "Mã hoàn chỉnh" để đối chiếu.
