# Bài tập CSS + JS mỗi ngày

Mỗi ngày một bài ngắn (30–45 phút) kết hợp CSS và JavaScript thuần. Từ bài 002 trở đi dùng Tailwind CSS v4 (đã gắn sẵn qua CDN trong `starter/index.html`, không cần cài, cần có mạng); bài 001 dùng CSS thuần. Cách dùng: mở thư mục `starter/` của bài (bài 001 có `style.css` dựng sẵn `:root` và reset; từ bài 002 chỉ có `index.html` đã gắn Tailwind và `script.js` trống, các class cần dùng được gợi ý trong file `.md`), đọc file `.md` cùng tên với thư mục bài, làm theo phần gợi ý từng bước, tự kiểm tra bằng checklist, rồi mới mở `solution/` hoặc phần "Mã hoàn chỉnh" để đối chiếu.
